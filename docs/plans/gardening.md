# Feature: Growing flowers with your thoughts

Users can grow flowers of different colours by using their diary entries as fertilizer.

## Mechanics

### Flower Growing

1. A user obtains a flower seed and plants the seed.
2. The user submits diary entries to obtain fertilizer which is given to the flower.
3. When the flower is ready to harvest, the user can add the flower to their collection and sell it for currency.

### Flower Arranging
1. The user can choose any amount of flowers from their collection.
2. Along with the flowers chosen in the last step, the user can choose a limited amount of accessories.
3. Flowers can only be placed in the vase, but accessories can be placed anywhere in the frame.
4. The user can save their arrangement as an image file.
