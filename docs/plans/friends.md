# Feature: Checking in on your friends

See what flowers your friends are growing.

## Mechanics

### Friend List

1. A user should be able to search for other users and send friend requests.
2. The user can accept or reject friend requests.
3. The user can also see who is in their friend list.

### Peeking

1. A user can see the current growing flower of another user.
2. The user can choose to help water the flower, speeding growth of the flower.

### Gifting

1. After [arranging flowers](./gardening.md#flower-arranging), a user can choose to send flowers to any friend.
2. The user can choose to also include a message to the recipient.
